SISTEMAS OPERATIVOS

Arquitectura y Gestión de Recursos Digitales

1. ¿Qué es un Sistema Operativo?

Un Sistema Operativo (SO) es el software principal o conjunto de programas fundamentales que gestiona el hardware de una computadora o dispositivo móvil, sirviendo como intermediario entre los componentes físicos (CPU, memoria, disco) y las aplicaciones ejecutadas por el usuario final.

Sin el Sistema Operativo, una computadora sería un conjunto de componentes inanimados, ya que este proporciona la interfaz de interacción, administra los recursos del sistema y garantiza la ejecución segura y coordinada de múltiples tareas simultáneas.

⚡ Rol Clave del Sistema Operativo

Actúa como un administrador de recursos que decide qué programas tienen acceso a qué recursos físicos y en qué momento, optimizando el rendimiento y protegiendo el sistema contra fallos de ejecución.

2. Funciones Principales del Sistema Operativo

Los sistemas operativos modernos desempeñan actividades críticas divididas en los siguientes pilares de gestión:

🖥️ Gestión del Procesador

Administra la asignación de tiempo del procesamiento (CPU) entre múltiples procesos activados mediante algoritmos multitarea.

🧠 Gestión de Memoria RAM

Asigna y libera espacio de memoria principal para cada programa en ejecución, previniendo invasiones de memoria.

💾 Gestión de Almacenamiento

Organiza los datos en archivos y directorios en discos SSD/HDD, controlando el acceso, lectura y escrituras.

🔌 Gestión de Dispositivos

Utiliza controladores (drivers) para facilitar la comunicación entre el sistema y periféricos como teclado, mouse o monitor.

Otras Funciones Cruciales

  • Interfaz de Usuario (GUI / CLI): Proporciona un entorno gráfico intuitivo (ventanas, botones) o una línea de comandos para interactuar directamente con el sistema.
  • Seguridad y Control de Acceso: Autentica usuarios, cifra credenciales y otorga privilegios diferenciados para proteger archivos del sistema contra accesos no autorizados.
  • Gestión de Errores y Diagnóstico: Detecta fallos en el hardware o en el código de las aplicaciones e informa al usuario sin comprometer la estabilidad global de la máquina.

3. Ciclo de Vida de un Proceso en el SO

Un proceso es un programa en ejecución. El sistema operativo se encarga de alternar constantemente el estado de cada proceso para lograr un rendimiento fluido:

  • Nuevo (Nuevo): El programa está siendo cargado en la memoria RAM desde el disco duro/SSD.
  • Listo (Ready): El proceso está en espera de que el planificador de la CPU le asigne tiempo de procesamiento.
  • En Ejecución (Running): Las instrucciones del programa están siendo procesadas activamente por la CPU.
  • Bloqueado / Espera (Waiting): El proceso espera un evento externo, como la lectura de un archivo o entrada del usuario.
  • Terminado (Terminated): El programa ha finalizado y el SO libera la memoria RAM asignada.

5. Arquitectura del Kernel y Sistemas de Archivos

Tipos de Núcleos (Kernel)

  • Kernel Monolítico: Todos los servicios del sistema (controladores, gestión de memoria, archivos) se ejecutan dentro del núcleo. Ejemplo: Linux, Android.
  • Microkernel: Solo las funciones indispensables residen en el núcleo; el resto corre en espacio de usuario de forma aislada. Ejemplo: QNX, Symbian.
  • Kernel Híbrido: Combina la rapidez monolítica con la arquitectura modular del microkernel. Ejemplo: Windows NT, macOS (XNU).

Sistemas de Archivos Populares

Un sistema de archivos determina cómo el SO organiza y recupera la información en las unidades de disco:

  • NTFS (Windows): Soporta permisos avanzados de acceso, cifrado y recuperación de errores.
  • ext4 (Linux): Eficiente, rápido y optimizado para el manejo masivo de archivos pequeños y grandes.
  • APFS (Apple): Diseñado específicamente para unidades de estado sólido (SSD) con cifrado nativo.
  • FAT32 / exFAT: Formatos universales altamente compatibles entre diferentes marcas de hardware.
