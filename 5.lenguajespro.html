Tema 5: Desarrollo de Software y Lenguajes de Programación

Ciclo de vida del software (SDLC)

El Ciclo de Vida de Desarrollo de Software es el marco estructurado que define las tareas en cada etapa del proceso:

01. Planificación

Se define el alcance general del proyecto, los recursos necesarios, los tiempos estimados y la viabilidad técnica.

02. Análisis de Requerimientos

Se recopila y detalla exactamente lo que el cliente o el usuario final necesita que el sistema realice.

03. Diseño

Se crea la arquitectura del software, los diagramas de bases de datos y la estructura visual de la interfaz.

04. Implementación

Fase activa donde los programadores escriben todo el código fuente utilizando los lenguajes elegidos.

05. Pruebas (Testing)

Se somete el sistema a revisiones para detectar errores (bugs) y garantizar que cumpla con lo requerido.

06. Despliegue y Mantenimiento

El software se lanza al entorno real y se le aplican actualizaciones continuas o correcciones futuras.

Diferencia entre Lenguajes Compilados e Interpretados

Lenguajes Compilados

Traducen todo el código fuente a código de máquina (binario) antes de ejecutarse.

  • Ventaja: Velocidad de ejecución sumamente alta.
  • Desventaja: Menor portabilidad por sistema operativo.
  • Ejemplos: C, C++, Rust, Go.

Lenguajes Interpretados

Un intérprete lee y ejecuta el código línea por línea en tiempo real durante su uso.

  • Ventaja: Alta portabilidad y flexibilidad.
  • Desventaja: Suelen ser más lentos en rendimiento.
  • Ejemplos: Python, JavaScript, PHP.

El Rol de HTML, CSS y JavaScript

Las tres tecnologías base que estructuran la experiencia web del lado del usuario (Front-End):

HTML

Es el esqueleto y la estructura semántica de la web (textos, imágenes, enlaces, formularios).

CSS

Es la capa visual y de diseño (colores, fuentes, efectos glassmorphism y adaptabilidad responsive).

JavaScript

Es el motor de lógica e interactividad en tiempo real (respuestas a acciones, validaciones, APIs).

Tema 5: Desarrollo de Software y Lenguajes de Programación

Ciclo de vida del software (SDLC)

El Ciclo de Vida de Desarrollo de Software (SDLC, por sus siglas en inglés) es un marco de trabajo que define las tareas realizadas en cada paso del proceso de desarrollo. Un ciclo típico incluye:

  1. Planificación: Se define el alcance del proyecto, recursos, tiempos y viabilidad.
  2. Análisis de Requerimientos: Se recopila lo que el cliente o usuario final necesita que el sistema haga.
  3. Diseño: Se crea la arquitectura del software, los diagramas de base de datos y la interfaz de usuario (UI).
  4. Implementación (Desarrollo): Es la fase donde los programadores escriben el código fuente utilizando los lenguajes definidos.
  5. Pruebas (Testing): Se verifica el funcionamiento, buscando errores (bugs) y asegurando que se cumplan los requerimientos iniciales.
  6. Despliegue: El software se lanza al entorno de producción para que los usuarios puedan utilizarlo.
  7. Mantenimiento: Actualizaciones, corrección de errores reportados y mejoras de rendimiento a lo largo del tiempo.

Diferencia entre lenguajes compilados e interpretados

Lenguajes Compilados

Estos lenguajes utilizan un programa especial llamado compilador para traducir el código fuente escrito por el humano a código de máquina (binario) antes de que el programa se ejecute.

  • Ventaja: Su ejecución es muy rápida al ser código nativo.
  • Desventaja: El proceso de compilación puede ser lento y el código suele ser específico para un sistema operativo (menos portable).
  • Ejemplos: C, C++, Rust, Go.

Lenguajes Interpretados

En estos lenguajes, no hay una fase previa de compilación a binario. Un programa llamado intérprete lee y ejecuta el código línea por línea mientras el programa está en funcionamiento.

  • Ventaja: Gran portabilidad (el mismo código corre en casi cualquier sistema con el intérprete) y mayor facilidad para detectar errores en tiempo de ejecución.
  • Desventaja: Suelen ser más lentos que los compilados, ya que deben "traducir" el código mientras se ejecutan.
  • Ejemplos: Python, JavaScript, PHP, Ruby.

El rol de HTML, CSS y JavaScript en el desarrollo web

En el ecosistema web, estas tres tecnologías forman la base fundamental del desarrollo Front-End:

  • HTML (HyperText Markup Language): Es el esqueleto de la web. Se encarga de organizar el contenido (títulos, párrafos, enlaces, formularios, imágenes) mediante etiquetas semánticas.
  • CSS (Cascading Style Sheets): Es la "capa de pintura" y diseño. Define los colores, fuentes, espaciados, animaciones y cómo se distribuye el contenido en diferentes dispositivos (móviles, tablets, escritorio).
  • JavaScript: Es el cerebro del sitio. Proporciona la capacidad de crear comportamientos dinámicos, como validar formularios, consumir datos de una API (traer información externa), modificar el contenido de la página sin recargarla y crear experiencias interactivas complejas.
